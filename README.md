# 🤖 Aura AI – Chatbot

**Aura AI** is a modern and interactive chatbot interface built using HTML, CSS, and Vanilla JavaScript. It provides a clean and user-friendly environment for interacting with a chatbot through a simple messaging interface.

## ✨ Features

- Clean and modern user interface
- Interactive chat interface
- Send messages and receive chatbot responses
- Typing indicator for a better chat experience
- Enter key support for sending messages
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Chat functionality and interactions

## 📁 Project Structure

```text
aura-ai-chatbot/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/aura-ai-chatbot.git
```

2. Open the project folder in VS Code.

3. Open `index.html` using the Live Server extension.

4. Start chatting with Aura AI!
